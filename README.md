# Tower-Defence-Game

This tower defence game is about protecting a tower from rounds of enemies. Through the use of skills and skillpoints, the player is able to use wizards to defend the tower. 


Player Movement:
Arrows(Up, Left, Down, Right)/ WASD to move the camera in the respective directions (W/Up: Move Forwards, A/Left: Move Left, S/Down: Move Backwards, D/Right: Move Right)
Right Click + Mouse Movement to angle view of the map
Left Shift to move the camera view downwards
Spacebar to move the camera upwards

Wizards cannot be placed in enemy path and other restricted areas(e.g. top of walls)
Wizards can't be place in very clos proximity of each other(touching)

Enemies follow one path towards the Tower
